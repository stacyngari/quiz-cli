# Quiz CLI

## Description
A simple trivia game built with JavaScript and Node.js. Players answer multiple-choice questions and get their final score and time taken.

## Features
- Multiple-choice questions
- Feedback on answers
- Score tracking
- Timer
- Option to play again

## How to Run
1. Install Node.js.
2. Open the project folder in the terminal.
3. Run `node quiz.js`.
